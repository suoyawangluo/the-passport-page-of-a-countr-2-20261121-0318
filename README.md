An invented passport spread for the Republic of Veskar, a North Atlantic island republic: the data page of Elin Marta Solberg, a herring-fleet seafarer from Havnestad, with arrival and departure stamps from Nordmark, Ostfjord and Talvik, a machine-readable strip, and a seasonal crew visa valid during the herring season only.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (1024×1024, rendered from `design.html` with a local headless browser) to `/output/entry.png`, deterministically — both runs write identical bytes.
